# Current-interface capture

The [desktop](screenshots/workspace-current.png), [phone](screenshots/workspace-mobile-current.png) and [playback clip](demo-current.mp4) were captured from the local application on 26 October 2026, using the packaged controlled synthetic recording and the default classical estimator. The interface and measurement code match [7dbfef2](https://github.com/nazeeh111/VibeScope/commit/7dbfef264152a27fcbfe16625573d32e351c18fb).

The run recovered **7.29996 Hz** and **0.27989 px**, with the stationary reference applied and no physical scale entered. These are results for the controlled synthetic clip, not independent physical calibration or diagnostic validation.

The silent clip shows synchronized playback, pause, seeking and playback to the end. Analysis finished before recording began; this is not a processing-speed demonstration. The result area is cropped for readability, with the synthetic-data warning retained. The full workspace is shown in the stills.

The [original workflow tour](demo.mp4) remains available and shows the earlier interface.
